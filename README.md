# UNIQ

this is certification management project

## Prerequisites

Make sure you have the following software installed:

- Node.js: Download and install Node.js version ">=18.0.0 <=20.x.x"

- Pnpm: Install globally using npm:

```
npm install --global pnpm
```

## Installation

To install the project dependencies, follow these steps:

1. Clone the repository:

```
git clone https://pragnikadia@bitbucket.org/incipientinfo-node/uniq.git

```

2. Navigate into the project directory:

```
cd uniq
```

3. Install the dependencies:

```
pnpm install
```

## configuration

1. Copy the example environment file to create your .env file:

```
cp .env.example .env
```

2. Open .env in a text editor and configure the necessary environment variables.

## Usage/Examples

Once the environment is set up and dependencies are installed, you can build and start the application:

1. To Start the application as production mode:

```
pnpm run prod
```

2. To Start the application as development mode

```
pnpm run dev
```
